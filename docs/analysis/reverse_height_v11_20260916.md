# v11：平地倒退与台阶高度并行训练

## 训练内容

总环境分配继续使用 v10：平地25%、上楼25%、下楼20%、其他地形30%（其中起伏路面占总数约15%）。
平地池内三等分为：原地转向、倒退/前进往返、普通目标行走及90°/180°转身。
每项约占总环境的8.3%；倒退练习不占用上下楼环境。

倒退池在平地中心附近，以固定世界+X朝向，在x=±2.5m之间往返：

- 每次新回合先向后方端点倒退，真正发送负前向速度，范围0.2–0.6m/s。
- 到达后向前返回，保持相同朝向，避免长时间倒退离开训练区域。
- 大角度朝向误差先转正，再平移；允许不超过0.15m/s的横向回正速度，保持在往返中心线附近。
- 原有速度跟踪奖励支持负速度，站立和抬脚奖励也按速度模长判定，倒退不会被误当成站立。
- 转向池、倒退池不参与普通平地提速和到达目标的升档统计。
- 新增 reverse_seconds、reverse_tracking、reverse_actual_vx、reverse_command_vx 指标；负vx代表倒退。
- 人工目标仍优先于专项练习。普通目标控制依然采用先转向再前进；专项训练给策略增加负速度指令能力，不自动改变所有后方目标的导航方式。

## 台阶高度持续自适应

继续使用 adaptive_stair_curriculum，没有冻结高度。
每个上下楼方向仍按50%当前高度、20%低台阶提速、20%降一档复习、10%更高台阶挑战分配。
满足至少100次尝试、至少60秒课程窗口且通过率≥80%时升一档，最高20cm。
保留17级楼梯、不要求终点站稳、平地3m/s/楼梯1.5m/s速度上限以及v9奖励和视觉裁剪。
从49000存档恢复时，上楼主档12cm、下楼14cm；版本变更清空旧成功统计，重新收集证据，不清零高度档位。
