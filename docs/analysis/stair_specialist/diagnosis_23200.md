# 第 23200 轮：楼梯零通过率诊断

结论：主要阻塞是训练动作探索噪声与严格停稳判定不匹配，不能把课程的零通过率解释为策略完全不会爬楼。新增的每帧角速度范数 <0.3 rad/s 且连续保持约 1 秒的条件，对随机采样动作过于严格。

## 对照方法

使用同一 `model_23200.pt`、种子 42、64 环境、当前保存的地形分组与难度。每种模式运行 2200 步（44 秒仿真时间），冻结策略与课程，不进行参数更新。

两个模式均使用干净的 PLAY 观测：一次采用策略均值动作，一次从相同策略的动作分布采样。后者用来隔离动作探索噪声的影响，并不等同于完整训练中的全部观测噪声和随机化。

另用独立计时器复算完成判定，核对课程读取发生在状态清空之前。独立计时与实际计时的 1 秒达标次数相同，未发现计时器先清零、坐标重复偏移等证据。

## 结果

- 均值动作：上楼 44 个结束回合，36 次通过（81.8%），1 次失败终止；下楼 26 个结束回合，23 次通过（88.5%），无失败终止。
- 随机动作：上楼 45 个结束回合，44 次曾接近目标，41 次曾同时满足终点几何和姿态条件，3 次失败终止；下楼 26 个回合，26 次曾同时满足终点几何和姿态条件，无失败终止。最终严格通过均为 0。
- 随机动作到达目标附近的帧中，上/下楼约 95.4%/99.0% 满足组合几何条件，92.8%/93.9% 的平移速度低于 0.2 m/s，但仅 19.1%/19.4% 的角速度范数低于 0.3 rad/s。
- 随机动作下最长连续满足所有条件仅 0.12/0.14 秒；均值动作可达 14.46/15.08 秒。一个不合格采样帧会立即清空连续计时。
- 均值动作“曾经停稳 1 秒”共 60 次，“回合结束仍停稳且无失败”共 59 次；因此仅在结束时检查会损失部分成功记录，但并非本次零通过率的主因。

这些是有限样本下、当前低阶楼梯的结果，不代表已经掌握高台阶，也不能单凭此测试判断平地步态和高速能力是否完全保留。

## 建议修正方向（本次未修改正式课程）

1. 楼梯穿越和终点停稳分开记录，不再把瞬时低角速度作为穿越成功的必要条件。
2. 保留进入终点平台、姿态安全、无失败及低平移速度要求；停稳采用短窗口内的平均速度或允许少量波动的比例条件，而不是要求 50 帧全部低于角速度阈值。
3. 角速度和更严格的停稳质量保留为评估指标；升级规则用含噪训练回合验证后再上线。
4. 不需要因为本次零通过率重置模型或降低 AMP 权重。后续可从当前模型续训修正后的课程。
