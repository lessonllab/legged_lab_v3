# 中间检查点统一评测

8 个模型：23600、24500、25500、26500、27500、28500、30000、31800。冻结策略和课程，不更新权重。

## 评测条件

- 同一场景、192 个环境、相同案例分配、seed 42；每个模型运行 2001 步，约 40 秒模拟时间。
- 上楼、下楼分别固定 8/10/14 厘米，速度上限分别 0.45/0.65 m/s；平地固定 0.8/1.2/1.8 m/s。目标附近仍会减速，速度上限不是全程恒速指令。
- 使用 PLAY 初始化分布、确定性动作，无策略观测噪声。环境后续重置随各模型轨迹发生，不能视为每一帧完全相同。
- 只统计完整结束的回合；最后不足一个回合的片段不纳入。摔倒更频繁的模型可能产生更多短回合，CSV 保留每个案例的回合数量。
- 本表每个高度对两个速度案例的通过率等权平均，避免不同案例的回合数量改变权重。
- 完整通过要求：曾满足 1 秒滑窗（至少 90% 帧满足平台/直立条件、平均平移速度低于 0.2 m/s），且回合结束时仍符合平台几何条件、没有失败终止。
- 平地实测速度取指令平移速度大于 0.3 m/s 的帧；跟踪分数为环境原有 moving_tracking_exp_vel_xy 的回合均值，统计窗口不同，不能互相直接换算。
- 单个种子的对照用于定位训练阶段，不足以证明最终泛化能力；高速度和风格奖励都不能直接证明步态自然。

## 对当前训练的判断

- 在这 8 个采样检查点中，25500～26500 是值得保留的阶段。针对 8cm 低速上楼，26500 是优先恢复候选；25500 在部分 10cm 案例中更好。不能据此声称某一个模型在所有场景下最优。
- 第一次明显回落出现在 26500 与 27500 两个采样点之间；30000 有部分恢复，31800 的低速上楼进一步退化。没有评测两点之间每一个检查点，不能定位到具体的一次更新。
- 最新模型在低速上楼时趋于停滞；较高速条件还存在到达后的停稳/保持不足。结果支持任务行为发生退化，但没有证明是哪一个奖励项或优化器设置造成，不能把相关性当成根因。
- 平地不能一概判定为全面退步：最新模型在固定 1.8m/s 速度上限下的跟踪分数略好，但平均实际速度仍低于这一上限；早期模型跑得更快，同时有明显超速和低跟踪分数。
- 高台阶上楼尚未稳定掌握。中期模型在 10cm 上楼的确定性完整通过率约 25%～36%，14cm 均不足 10%。
- 本轮没有对步态风格做视觉评分。所有模型均按原权重加载；没有修改训练奖励、参考动作、策略参数或课程实现。新增内容只有独立评测脚本与分析产物。
