# 14700 轮后的支撑转换接口实验

用户批准：从现有 14700 轮开始，先训练 1000 次 PPO 更新，结合播放检查效果，保持原步态。

本轮是下一次触地位置、剩余步时、触地后身体与承重状态的预测接口实验。尚未实现多步候选序列搜索、可行性判别器或候选评分选择，不能把本轮称作完整的联合规划方法。

## 固定条件

- 起点：`2026-10-13_17-21-44-385400_gait_preserve11700_3000_4096/model_14700.pt`。
- 每组 4096 环境、1000 次更新，结束于 15700 轮。50% 平地、50% 正向/斜向桩路，保留难度升降、全部已有泛化类型和 50% 规则地图回放。
- 保留全部现有运动、落脚、航向、终点奖励及 11700 轮软保持项。没有新加姿态惩罚，没有提高摆臂惩罚。
- 控制频率 50 Hz，物理频率 200 Hz，29 维全身关节动作，原观测 480+225+3 维。
- 桩路出生面向选定路线，给本体向前指令。本轮不是身体朝向固定的八方向侧移实验。
- 感知仍是现有局部高程图，不是新增深度相机或真实雷达管线。

## 两组及模型边界

普通续训：沿用 14700 配置和优化器，全部原策略参数可训练，额外 1000 次更新。

新接口：冻结 14700 原策略 MLP 和归一化，保留原高斯动作分布，新增预测分支和零初始化的小幅残差。腿部/腰部/手臂目标角度修正分别至多 0.08/0.04/0.03 rad。仅在纯前进命令且原高程观测中有前方间隙时启用。平地、站立、后退和转向的确定性动作保持原策略函数；闭环仍需评估。

输入预测分支与原策略完全相同。每只脚预测 15×15 离散落脚区域分布，以及剩余触地时间和触地后 120 ms 的本体速度、倾斜、偏航角速度、竖直承重占比。残差读取整个离散分布和状态预测，不把多个桩子的位置平均成一个脚目标。仿真真值只生成训练标签，不能流入推理输入。

落脚标签使用足踝参考点的水平投影，不等同于整只脚的安全支持区域。门控关闭时动作函数保持原样；平地地图边界也可能产生间隙观测，因而不能保证所有平地状态的门控始终关闭。

标签只使用同一回合中实际观测到的未来事件。重置前未观察完的支撑转换不标为成功。当前模型只预测未来状态，没有“成功/可行”标签，因而不能宣称它预测了长期可行性。

普通续训与新接口的差异同时含冻结方式、网络和辅助监督；这是等更新预算的工程对照，不是隔离单一机制的消融。

## 本轮验收与播放

固定第一回合，关闭观测噪声和推力，保留共享物理随机化，两策略在同一物理环境和相同初始状态下测试。

1. 已有地图：32 个平地例 + 64 个桩路例，正向/斜向各四条路线，L8/L10，规则及组合泛化桩。
2. 未见地图种子 1729：相同地形生成规则、未用于训练的桩位，横纵扰动和组合泛化。它验证同族未见地图，不代表任意新地形。
3. 分别比较原始 14700、新接口 15700、普通续训 15700。记录到达、停车、失败以及偏航、速度误差。
4. 检查过桩段的膝关节幅度、左右支撑交替、腾空、身体晃动、摆臂协调和动作变化，避免仅凭通过率选择更僵硬的策略。
5. 同场景并排播放常规和泛化桩，涵盖起步、连续过桩及上平台停车。视频若由已记录的 Isaac 状态渲染，必须标明是状态重放，不能冒充 MuJoCo 物理验证。
6. 如新接口退步，保留结果用于诊断，不替换 14700 原模型，不把辅助预测训练分数当作通行能力提升。

新接口与普通续训均已完成 1000 次更新，最终为 15700 轮；新接口保存时基础网络与 14700 逐张量一致。已有地图与未见地图的四组配对评估均完成。原模型与实验输出分别存放，不删除源检查点。

## 已有地图结果

- 原始 14700 与新接口 15700 均为 64/64 到达、64/64 稳定停车，无失败。这个场景集存在通过率天花板，不能据此证明新方法提高了通过率。
- 过桩段身体晃动从 1.573° 降到 1.345°；过桩膝关节幅度从 46.54° 到 45.86°，左右交替触地比例均为 1.0。没有看到以缩小步幅或双脚跳替代行走的现象。
- 前 0.5–3 秒平均绝对偏航从 1.688° 到 1.827°。根据回放观察，另外补充整段过桩与终止时朝向指标：整段 2.145° → 2.596°，终止时 1.333° → 1.959°。这些整段指标是看回放后追加的诊断，不是预先定义的新主终点。
- 过桩肩关节幅度从 19.33° 到 17.62°；左臂与右脚的步频范围内相关性 0.685 → 0.426，右臂与左脚 0.240 → 0.289，协调性改善不一致，不能以摆臂减小宣称更像人。
- 已查看正向 L10 组合泛化、斜向 L10 组合泛化、相对退步最大样本、平地前进的关键帧和短步态片段分帧。当前观感与数据一致：原步态大体保留，仍连续迈步及停车，部分路线的后半程偏航增大。
- 平地早期窗口新修正为零，基础确定性动作函数保持；两次物理复位后的闭环轨迹仍有细小数值差别，不能把这部分差别当作新方法改进平地能力的证据。原模型的低速原地转向与横移仍不足，本轮未修复。
- 预测头在过桩且门控开启的观测标签上，足踝投影位置平均误差约 4.27 cm、剩余触地时间平均误差约 32.3 ms。这只证明预测接口学到了相关信息，尚未证明预测分支本身导致控制改善。

## 未见地图与本轮结论

- 未见地图的 128 个桩路回合中，原始 14700、普通续训 15700、新接口 15700 均为 128/128 到达及稳停，无失败。新地图栅格指纹与训练地图不同，生成种子为 1729；测试覆盖 L8/L10、正向/斜向各四条路线、变体 3/4/6/7，属于同族布局泛化。
- 原始 14700 与新接口的配对测试合计 192 个桩路回合。过桩身体晃动 1.591° → 1.357°，约减少 14.7%；整段平均绝对偏航 2.131° → 2.545°，终止时绝对偏航 1.408° → 1.907°。
- 同一只脚两次落地前进距离 0.4898 m → 0.4897 m；左右脚触地间隔 0.3428 s → 0.3402 s。过桩膝关节幅度 46.63° → 45.89°，左右交替触地比例均为 1.0。回放没有明显缩步、双脚跳或锁臂，动作外观总体接近原模型。
- 摆臂并非全面改善：左臂与右脚步频范围内相关性 0.686 → 0.424，右臂与左脚 0.236 → 0.281。不能把摆臂幅度或速度下降直接解释为更自然。
- 未见地图的普通续训对照中，普通组整段偏航约 1.870°，新接口约 2.505°；身体晃动普通组 1.476°，新接口 1.370°。普通组两侧臂腿协调相关性约 0.830/0.449，新接口约 0.426/0.275。普通续训的表现更均衡，新接口尚未胜过同预算基线。
- 同一新模型在两组配对测试中的重复测量存在小幅差别，不能把数值极小的足底支持差异单独当作收益。各组通过率都达到此测试集上限，本轮没有证明通过率提升。

本轮选择：保留原始 14700 为主基线；普通续训保留作候选和对照；新接口保留作实验版本，不替换原模型。新增训练止于本轮的每组 1000 次更新。

建议下一阶段先隔离预测分支的贡献，并处理修正动作引入的偏航与臂腿相位变化，随后再扩大任务难度。不能仅凭预测误差较低宣称已经实现联合落脚规划。本轮未继续执行新的训练阶段。

## 结果位置与播放

- 原始记录、四组配对数据、指标审计、视频及汇总：`.runtime/support_transition14700_stage1/`。
- 汇总：`summary.json`；实验定义与检查点指纹：`experiment_manifest.json`。
- 对照页：`http://127.0.0.1:8094/support_transition_stage1/`，包含固定样本及相对退步最大的样本。
- 新接口实时 IsaacLab 播放：端口 8095，默认正向路线 0、L10、组合泛化变体 7、0.75 m/s，以自动过桩停车模式启动；可以调场景并切换手动指令。启动与运行状态分别记录在该目录的 `live_play_launch.json` 及 `.runtime/beamdojo_play_8095.json`。修正播放启动模式后，已核验至少连续 7 个回合到达并停车、零失败；这是同一播放场景的运行检查，不算额外独立泛化样本。
- 本轮仅一个训练种子；理想高程图输入、桩顶等高。回放由真实 Isaac 状态渲染，MuJoCo 只负责姿态显示，不是新的 MuJoCo 物理复验。实机、真实传感器、高低混合桩与更强分布外泛化尚未验证。

## 执行记录

2026-10-16，普通组保存到 15100 轮后，主机在并行创建评估场景时内存不足，内核终止了训练进程，最后 32 次未保存更新丢失。后续改为串行：新接口完整 1000 轮、原模型对照评估与播放、普通组从 15100 补齐剩余 600 轮、其余对照评估。普通组最终检查点仍累计 1000 次有效更新，但经历了一次环境重新初始化。

原生预检（不做 PPO 更新）观测到 163 次触地、912 条监督标签，辅助损失可回传有限梯度。核心测试覆盖零残差动作一致、目标修正上限、原 PPO 与辅助梯度共同更新、落脚坐标变换、重置隔离及离线评估时间对齐。15000 轮存档已核验基础网络全部 8 个参数张量与 14700 完全一致，新分支权重已更新。

实时播放首次启动时，交互控件默认进入手动速度模式，关闭了自动终点停车，导致到达外环后继续行走。已为播放器新增显式 `--start_auto_course` 选项，默认保持自动任务模式且保留手动切换控件，重新启动后核验正常。初次播放的启动参数、状态和日志保存在 `live_play_initial_manual_*`，未计入配对评估结果，训练奖励和模型未因此改变。
