# 承重脚支撑与边缘约束（2026-09-11）

## 实现

应用于 Instinct 崎岖与 Warmup 任务；旧的非 Instinct 任务不受影响。
每只脚增加一个 terrain-only RayCaster，以脚的完整姿态投射沿脚底法线的射线。
每只脚 55 条射线，其中 27 个脚底采样点、28 个外围采样点。
这些信息只计算训练奖励，不加入 actor、critic、AMP 判别器或实机策略输入。

核对当前 G1 USD 碰撞几何后，脚底采样覆盖 ankle_roll_link 局部
x=[-0.05,0.12] m、y=[-0.025,0.025] m，名义底面 z=-0.035 m。
外围延伸约 2–2.5 cm。它是几何支撑比例的近似，不是实际接触面积、压力分布或稳定裕度。

- `feet_support`，权重 -0.25：脚底采样点距名义底面不超过 2.5 cm 算作支撑。
  支撑比例低于 85% 时线性增加代价；无命中算不支撑。
- `feet_edge`，权重 -0.10：采样范围中相邻点沿脚底法线的高度差超过 5 cm，
  或存在无命中时施加代价。脚底与坡面贴合时不会把平滑坡面当成台阶。
- 两项只在连续接触至少 80 ms、法向接触力的世界竖直分量超过 20 N 时生效。
  20–100 N 之间线性增加负载系数，减少卸载/蹬离阶段的惩罚。
- 使用负代价而非站立持续加分，两只脚合计每控制步最多 -0.014
  （最大未乘 dt 代价为 -0.7，控制周期 0.02 s）。
  原前进、速度跟踪、AMP 和地形课程保持不变。

权重与阈值是保守初值，尚未通过长训选择。稳定接触阶段也可能存在正常滚动支撑，
这些代价不能完全区分所有正常蹬地与危险踩边，因此不应一开始大幅提高权重。

## 验证

17 项 CPU 回归测试通过（`unit.log`），涵盖安全支撑、部分悬空、外围边缘、
无命中、摆动脚、弱接触、落地缓冲、平滑坡面，以及已有视觉与 AMP 测试。

4 环境实际射线投射到专门构建的 20 cm 台阶，见 `step_test.json`、`step_test.log`：

- 上层平台中央和下层平台中央：支撑比例均为 100%，两项代价均为 0。
- 脚底仍被完整支撑、前方外围圈遇到边缘：支撑代价为 0，边缘代价触发。
- 部分脚底越过边缘：支撑比例为 33.3%，两项代价均触发。
- 将相同几何的承重力设为 0，所有场景两项代价均为 0。

台阶测试的射线来自真实仿真，承重力和接触时长固定为 100 N、1 s，目的是隔离几何逻辑。
这不是自然行走的通过率测试，也不能证明已经减少策略踩边频率。

最终代码在崎岖任务中以 128 环境完成 3 轮 PPO+AMP 更新，共 9216 个环境步，
实际接触传感器参与奖励计算，损失有限，两项奖励已注册，见 `train.log`。
保存于项目根目录下
`logs/rsl_rl/g1_amp_depth_instinct_v2/2026-09-11_12-59-42_foot_support_smoke_final/model_2.pt`。
短测中支撑项非零，边缘项接近零；随机初始短片段没有足够台阶落脚，不能作踩边改善结论。

## 训练与观察

正式训练命令见 `../../g1_depth_instinct.md`，run_name 为 `foot_support_v2`。
目前没有启动长期训练；旧模型不会因修改奖励而自动改善。
新日志会显示 `Episode_Reward/feet_support` 与 `Episode_Reward/feet_edge`。
后续应在相同地形、速度与随机种子下比较落脚支撑、踩边频率、完成率和前进速度；
不能只凭这两项惩罚变小判断效果，机器人少走或频繁跳跃也可能降低惩罚。
