# v6：视觉崎岖地形的风格与目标奖励修复

2026-09-13。任务注册名为 `LeggedLab-Isaac-AMP-Depth-Target-G1-v2`，配置版本为 v6。
本版依据 [v5 与本地 Instinct 源码的核对](../target_v5/instinct_style_balance_20260913.md)
修改奖励与判别器训练，并保留独立的 v5 训练/播放入口。

## 修改内容

令 `f(D)=max(0,1-(D-1)^2/4)`，`r_task` 为环境已按 `.02 s` 控制周期积分的任务奖励。
v6 实际使用 `r_total=r_task+.25*f(D)`。v5 使用 `.5*(r_task+.04*f(D))`；在相同
判别输出和任务奖励下，新版风格相对任务系数为旧版的 6.25 倍，总回报也相应改变。
两项奖励进入同一个 PPO 回报与优势计算；没有新增第二个 critic。

判别器配套设置：

- 670 维输入保留 10 帧×67 维物理量编码和原有固定缩放；关闭在线经验归一化。
- 两层 1024/512 ReLU 网络，策略/参考目标仍为 -1/+1 的 MSE。
- 对策略与参考合并样本计算梯度惩罚，系数 5。
- 所有参数平方和系数 `3e-4`，输出层权重平方和系数 `.04`。
- AdamW 学习率 `1e-4`、优化器 weight decay `.01`；显式正则与优化器衰减都启用。
- 当前 rollout，5 epochs×4 minibatches，每轮 20 次判别更新；不裁剪判别器梯度。

姿态与步态设置：

- 单脚支撑奖励同时支持平移和纯转向指令，权重 `.5`、速度阈值 `.15`。
- 到点站立改为全关节偏差项，权重 `-.3`、offset `4`，平移及转向均低于 `.15` 才启用。
- 骨盆与躯干各自的重力投影水平分量平方代价相加，统一权重 `-3`。
- 任一骨盆/躯干倾角超过 `1 rad` 终止；地面相对骨盆高度终止阈值 `.2→.35 m`。
  这是倒地保护，不能保证正常行走时膝盖伸展，也不是固定身高跟踪奖励。

前向深度相机与延迟图像、六类崎岖地形、参考动作镜像、目标进度课程、足底边缘支撑
奖励保持启用。执行器 PD、动作尺度、初始动作 std `.5`、可学习范围 `[.05,1]` 和
熵系数 `.006` 保留，探索强度是否下降需要观察，不能预先保证。

这是在当前视觉策略与 G1 动力学上的适配，没有完整复制 Instinct 的 MoE 与执行器。

## 开始正式训练

```bash
cd /home/ljc/legged_lab_v3
ISAACLAB_PYTHON=/home/ljc/isaaclab/bin/python bash scripts/run_with_rsl5.sh \
  scripts/rsl_rl/train.py \
  --task LeggedLab-Isaac-AMP-Depth-Target-G1-v2 \
  --viz none --device cuda:0 --num_envs 512 \
  --max_iterations 30000 --seed 42 --run_name target_v6_scratch \
  agent.device=cuda:0 agent.resume=false
```

输出目录 `logs/rsl_rl/g1_amp_depth_target_v6/`，每 500 轮保存。
512 环境作为本次单卡启动配置；与 v5 的 1024 环境相比，每轮采样量减半，不能只按
迭代轮数比较训练量，需同时看累计环境步数。本次没有启动长期训练。
使用独立目录从头训练，不加载 v5 或短测 checkpoint。

## 训练后如何判断是否改善

`Train/mean_reward` 仍记录任务回报；合成每步奖励看 `AMP/mixed_reward_per_step`。
同时检查 `AMP/raw_style_reward_per_step`、`AMP/weighted_task_reward_per_step`、
`AMP/weighted_style_reward_per_step`、风格零奖励比例、判别器两类得分及动作 std。
新旧版本的已加权风格奖励数值不能直接横向比较。

用相同地形、目标指令与随机种子做无采样噪声播放，比较骨盆高度、膝屈曲、单脚支撑、
滑脚、有效目标到达与摔倒。姿态自然与目标完成必须一起检查，不能只看平均地形等级或
判别器 loss。参考分布和训练后实际行为应单独测量。
