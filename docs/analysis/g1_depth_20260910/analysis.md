## 主要瓶颈

1. **未稳定进入更难地形。** 最近 1000 轮平均等级为 0；最后一次非零日志在第 8943 轮，
   此后截至快照全部为 0。任务仍然是崎岖地形，只是最低难度，不等于平地任务。
   当前课程要求离出生点的平面净位移超过 4 m 才升级（8 m 地形块的一半）。
   该指标不测量走过的路径长度；转圈也可能无法升级，所以不能单凭等级 0 判定机器人完全不走。

2. **前进跟踪仍不充分。** 指令前进范围 0.2–1.0 m/s，但 XY 误差约 0.688 m/s。
   success_rate 最近均值约 26.7%，其定义仅是 episode 平均 XY 误差 <0.5 m/s 且 yaw 误差 <0.4 rad/s。
   它没有要求穿越地形或存活到时限，因此不是崎岖路面通过率。

3. **AMP 饱和。** 最近策略判别分数约 -0.99916，示范约 +0.99822，判别损失约 0.00045。
   对当前 LSGAN 而言，这表明判别器轻易区分二者，并非动作模仿成功。
   风格奖励使用 `max(1 - (D - 1)^2 / 4, 0)`，D 接近 -1 时奖励接近零。
   这些分数来自判别器训练批次；日志没有单独记录在线风格奖励，不能由平均分数精确还原其期望值。

4. **动作随机性较高。** mean_std 从配置初值 0.5 增长到约 1.98，约为初值的四倍。
   action_rate 惩罚最近约 -0.836，动作变化较大。随机性是可学习的策略分布参数，
   不能直接当成确定性播放时的抖动，但值得检查探索奖励和动作幅度。

5. **近期改善有限。** 29000–29999 与最近 1000 轮相比：回报 15.01→15.06，
   XY 误差 0.678→0.688 m/s，跟踪成功指标 26.6%→26.7%，存活长度 888→881 步。
   这支持近期平台期判断，不表示之后必然完全无法进步。

## 日志口径与可能原因

`Train/mean_reward` 由 runner 记录环境原始任务奖励；PPOAMP 在内部将其与风格奖励按 0.5/0.5 混合。
所以总回报上涨不能证明 AMP 或视觉分支在变好。

现有角速度跟踪奖励权重为 2，平移为 1。最近对应奖励约 1.356 与 0.299；
结合低净位移和较大平移误差，策略可能偏向保持稳定、满足转向而没有充分前进。
这是需要播放验证的解释，不能仅凭奖励分解确认实际步态。

持续偏航指令（±0.5 rad/s）与按净位移升级的课程也可能不匹配。
AMP 饱和可能来自策略步态与示范差异，也可能涉及示范选择、观测历史或归一化；目前未定位唯一原因。
仅有这些日志也无法确认机器人是否使用了深度信息，需要深度消融评估。

## 建议的下一步顺序

1. 保留现有 checkpoint，对 10000、20000、31000 附近模型进行固定种子的确定性评估。
   先给 0.5 m/s 前进、零偏航，分地形记录实际前进距离、存活时间和跟踪误差，确认是站立、转圈还是步态问题。
2. 核对在线/示范 AMP 输入与归一化，增加独立的任务、风格、混合奖励日志；
   再根据结果调整判别器强度及探索奖励，避免把降低判别损失当目标。
3. 先建立直行任务，再逐步加入转向；若保留持续转向，课程应采用与指令匹配的进度指标。
4. 用相同种子比较正常、冻结和打乱深度输入，判断视觉是否真的带来通过能力。
   基础步行不稳定时，优先训练稳定教师，再蒸馏视觉学生，也是可选路线。

本次只做诊断，未自动停止长训练或更改实验。
