# 固定直行验证

模型：`2026-09-09_21-30-40_depth_baseline/model_31200.pt`。
目标是判断关闭转向后，是否能满足地形课程的 4 米净位移门槛。

## 验证方法

- 原视觉任务的崎岖地形网格，所有机器人从 0 级开始；20 秒一个回合。
- 固定本体坐标指令 vx=0.5 m/s、vy=0、wz=0，重置后的观测历史也使用相同指令；每步断言指令一致。
- 保留原参考动作初始化、CNN、深度历史、本体输入和动作尺度。
- 使用确定性动作均值，关闭观测噪声、质量和摩擦随机化；这是控制变量评估，不等同于训练时的随机动作统计。
- 在自动重置前的课程回调中记录终点；不更新地形等级。每个环境只计第一个完整回合，避免短回合反复重置造成采样偏差。
- 记录净位移、累计平面路径、存活时间、速度误差和超时/失败；没有训练模型或更改原训练配置。

## 第一组结果（seed 42，64 个回合）

- 0/64 达到 4 米；平均净位移 0.423 米，最大 1.806 米。
- 58/64 存活到 20 秒；其余 6 个回合提前失败。
- 全部回合平均路径长度 0.601 米。
- 只看存活到 20 秒的 58 个回合：平均净位移 0.331 米、路径长度 0.519 米、平均本体前进速度 0.0138 m/s。
- 全部回合的平均本体前进速度为 0.0998 m/s，被少数带有参考初速度、很快失败的回合抬高；不能用它代表稳定行走速度。

第一组已表明：取消转向后仍未达到升级条件，而且累计路径也很短，不能归因于“走了很多路但一直转圈”。

## 复现

在项目根目录使用用户的 Isaac Lab 环境：

```bash
source /home/ljc/isaaclab/bin/activate
bash scripts/run_with_rsl5.sh scripts/tools/verify_amp_depth_progress.py \
  --checkpoint logs/rsl_rl/g1_amp_depth/2026-09-09_21-30-40_depth_baseline/model_31200.pt \
  --output /tmp/straight_seed42.json --seed 42 --viz none
```

逐回合数据包含模型 SHA-256，见同目录 `straight_seed42.json`。

## 第二组与综合结论

seed 43 的 64 个回合：0/64 达到 4 米，平均净位移 0.449 米，最大 1.581 米；55/64 存活到时限。逐回合数据见 `straight_seed43.json`。

两组合计 128 个回合，0 个达到升级门槛，113 个存活到 20 秒。存活回合平均前进速度 0.0163 m/s，平均净位移 0.334 米，累计路径 0.524 米。

**当前模型在该评估条件下主要保持在出生点附近，基础前进能力不足；转向与课程规则的冲突不能单独解释不升级。** 不应仅降低升级门槛强行升难度，应先修复基础速度跟踪、排查 AMP 饱和，再进行相同协议复测。此次未测其他模型和地形等级，也未定位奖励、示范或视觉输入中的唯一根因。
