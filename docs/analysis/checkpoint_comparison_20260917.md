# v11 检查点对比：54000 / 55000 / 58999

日期：2026-09-17。冻结策略，未启动或修改训练。三个模型均完成五项测试，共 480 个首回合。

## 条件与局限

- 相同 seed=42、32 个环境、相同起始扰动和场景；已验证各模型对应案例的初始 XY 完全相同。
- 确定性策略，关闭策略观测噪声；只加载网络，不加载训练课程状态。
- 上下楼：17 级，阶高 20 cm，速度上限 0.65 m/s，60 秒上限；脚部与机身到达出口且未失败算通过，无站稳要求。
- 倒退：机身坐标速度指令 -0.4 m/s；左右转：角速度指令 ±0.6 rad/s，均持续 8 秒。不是“后方目标导航”的完整评估。
- 速度数据跳过初始 1 秒，先按每个机器人有效时间平均，再对 32 个机器人平均。转身漂移为距初始 XY 的时间平均距离。
- 单一场景与随机种子的有限测试，不代表广泛地形上的成功率；训练考核含不同速度与探索行为，不能直接和此次 play 通过率等同。

## 判断

55000 是本组测试中较均衡的续训候选，但上楼也仅 11/32 通过，不能称为已解决。58999 下楼速度更接近指令，转向漂移更小，但上楼全部超时，左转明显变慢。建议保留三者，优先以 55000 作为修复上楼停滞的候选基线，而不是直接从最终模型继续叠加难度。

上楼超时轨迹中，54000 和 55000 相对起点仅前进约 0.9–1.2 m；58999 仅前进约 0.78–1.02 m。问题位于前段台阶，不是终点站稳判定。奖励权衡、探索依赖等原因仍需针对性验证，此测试未证明单一因果。
