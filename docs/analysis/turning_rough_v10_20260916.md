# v10：转身和起伏路面补训

## 修改

- 长楼梯任务分配改为平地 25%、上楼 25%、下楼 20%、其他地形 30%。起伏路面独占总环境约 15%，其余非楼梯环境覆盖块状地形和两类坡面。
- 平地池每三个机器人中一个专练原地转向（总环境约 8.3%）：前向/侧向指令为零，角速度随机正负 0.3–1 rad/s。它们不参与平移速度或到达目标的升档统计。
- 其余平地机器人练前方、左/右 90°、后方 180°目标；目标在中心安全区域内裁剪，实际角度可能因边界裁剪而变化。人工指定目标优先。
- 新版指令器在偏航误差 20°以内保持原前向指令，20–70°之间线性减速，70°以上先转身。仍不要求倒退；侧向指令为零。该功能由长楼梯命令配置开启，其他旧任务默认不变。
- 非楼梯升档需要两个合格回合：无失败终止、至少一个有效目标到达、至少 1 m 的目标接近进度、2 s 的有效运动机会、平移跟踪 >0.6、转向跟踪 >0.5。两个连续失败/明显跟踪不良回合降一级。无需在终点站稳；楼梯自己的升高度规则不变。
- 新增 `turn_seconds`、`turn_tracking`、`turn_drift_mps` 指标，观察原地转向是否跟踪角速度、是否乱走。
- 课程版本 10、布局版本 `agility_v10`。从旧布局按同地形列/同上下楼方向映射，保留网络、优化器、楼梯高度和速度档位；清空不兼容的旧成功统计。新布局续训则正常恢复对应统计。
