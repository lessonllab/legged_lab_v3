# V12：低速跨阶、自然转向与块状地形续训

## 当前结论

已实现新的独立任务 `LeggedLab-Isaac-AMP-Foothold-G1-v0`。它从评估较均衡的 v11 `model_55000.pt` 分支续训，后续再次执行脚本会选最新正式 v12 检查点。新奖励是否改善行为，必须经过正式续训和相同条件的确定性评估确认；短测不构成能力提升证据。

## 借鉴的公开思路

1. [Hiking in the Wild / InstinctLab](https://arxiv.org/html/2601.07718v1)：脚部体积点与地形边缘的几何约束、可行目标采样、纯转向训练环境，以及人类动作先验。当前保留已有边缘安全项和 AMP，补充转向脚底接触运动与块状地形监督。
2. [InstinctLab 的步态奖励实现](https://github.com/project-instinct/InstinctLab/blob/main/source/instinctlab/instinctlab/tasks/parkour/mdp/rewards.py)：单支撑奖励同时支持移动和转向。直接奖励持续腾空时间可能无法区分有用迈步和持久单脚支撑，因此本地方案把纯转向改为有效落脚事件奖励。
3. [Humanoid Parkour Learning](https://arxiv.org/html/2406.10759v2)：不规则地形可以驱动抬脚，其实验提示持续腾空时间奖励可能与部分越障任务冲突。借鉴的是地形练习覆盖与不过度固定步态；本次没有照搬它的分形地形生成器或教师蒸馏架构。
4. [Perceptive Humanoid Parkour](https://arxiv.org/abs/2602.15827)：人类运动片段组合、专家跟踪和学生蒸馏可用于自然的复杂越障。这是后续数据与架构方向，本次没有引入其专家或运动库。

上述来源提供设计依据，不证明本地新奖励一定有效。短程前方地形监督、转向接触约束和条件化任务奖励的组合是本项目的候选方案；没有进行完整新颖性检索，不声称学术首创。

## 奖励调整

- 线速度奖励仍权重 3，但有移动指令时乘以沿指令方向的实际进展比例（截断 0–1）。0.2 m/s 正向或负向指令下，停住都不能拿这项奖励。静止指令仍奖励停止。
- 角速度奖励权重 1.5。移动任务需要平移进展；纯转向需要同方向的实际转动。专门的原地转速指令池不再被当作“目标朝向误差”惩罚。
- 存活权重从 3 降到 0.6，保留跌倒终止惩罚和姿态约束。
- 原 `dont_wait` 替换为权重 -1 的持续停滞项：移动阈值 0.08 m/s，沿指令方向的速度比例经过约 1 秒滤波，低于指令的 25% 才逐步惩罚。支持倒退，不罚主动停止或原地转向。
- 原地转弯：权重 -0.4 的承重脚底点速度惩罚。点速度包括脚部平移与角速度叉乘偏移，能发现“脚踝中心不动，鞋底在拧转”。卸载后代价淡出。
- 转向有效落脚奖励 0.08/次：摆动 0.08–0.8 秒、整只脚最低点抬高超过 2.5 cm、身体同向转过 0.04 rad、落地脚底点速度小于 0.25 m/s、左右交替。起摆时另一只脚必须支撑，双脚同时落地不得分。不是固定周期步态。
- 行走腾空奖励降至 0.15，时长截断为 0.3 秒，并排除纯转向，避免单脚长时间悬空累积收益。
- 前方净空权重 -0.6：每脚 24 个向下地形射线覆盖前后短距离，只找最近的向上高度突变，摆动脚需要越过该高度再留 3.5 cm 余量。不要求一次跨越两级，不把下坡、平面、缺失射线当障碍。替换旧的只适用于解析楼梯的净空项。
- 块状/起伏地形：增加权重 -0.3 的承重脚底支撑不足项和 -0.3 的异常横向碰撞项。足底支撑使用已有脚底传感器，不把所有靠近边缘都算碰撞。
- 保留楼梯现有脚部体积边缘、脚尖撞立面、承重悬空项。动作先验系数仍为 0.25，网络输入和参数形状不变。

前方射线只参与仿真奖励，策略仍通过原深度输入感知环境。射线阈值、奖励权重是首轮假设，需要通过对照实验调整。

## 课程调整

全体环境：平地 25%、上楼 25%、下楼 20%、块状 15%、起伏 10%、坡面 5%。块状从约 7.5% 提到 15%；平地仍包含纯转向和倒退练习。

楼梯回合期望分配：当前阶高普通速度 35%、当前阶高低速 15%、8 cm 高速 20%、低一级复习 20%、高一级挑战 10%。低速范围 0.2–0.5 m/s，每回合固定；普通阶高仍 0.55–0.75 m/s。阶高自适应继续运行，上限 20 cm；从 55000 恢复时保留上下楼 20 cm 主档和高速 phase 4。

低速练习单独记录尝试、穿越和满足速度的成功次数，不混入普通阶高晋级证据。块状记录尝试、失败和有效到达。转向/倒退同时记录专项样本数与指标总和，分析时用总和/样本数，避免非专项环境稀释。

## 验收及消融

扩展后的 `scripts/tools/compare_stairs_checkpoints.py` 支持 `slowup20`、`slowdown20`（0.3 m/s）、`boxes`（难度 3，0.6 m/s）、`rough`（难度 5，0.6 m/s），并支持 `--seed`。原来的上/下楼、倒退和左右转测试仍可运行。

```bash
ISAACLAB_PYTHON=/home/ljc/isaaclab/bin/python bash scripts/run_with_rsl5.sh \
  scripts/tools/compare_stairs_checkpoints.py \
  --checkpoints /绝对路径/model_55000.pt /绝对路径/新的模型.pt \
  --cases slowup20 up20 down20 boxes rough reverse turn_left turn_right \
  --num_envs 32 --seed 42 --viz none --device cuda:0 \
  --output docs/analysis/foothold_comparison.json
```

另用 seed 43、44 重复。楼梯按穿越/失败/超时分开统计；块状按存活、进展、到达次数统计；转向同时看角速度跟踪、位置漂移和视频里的抬脚/接触动作。不要用累计总奖励或单次不摔倒代替验收。

后方导航目标仍保留朝向误差代价，只有专门的原地转速指令池免除该项，避免旋转逃避前进任务。

建议先检查前 1000–2000 轮，若低速上楼仍普遍停滞或转向跟踪明显退化，不直接追加更多轮数。后续消融分别禁用转向脚底代价、有效落脚奖励或前方净空项，使用相同训练预算和多种子，才能判断每个新增项是否有贡献。当前没有进行完整消融。
