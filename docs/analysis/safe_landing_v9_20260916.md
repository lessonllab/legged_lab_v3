# 楼梯续训 v9：承重支撑与上楼净空

实施依据：`reward_audit_instinct_20260916.md`。用户授权修改并开始续训。

## 生效修改

- 保留 Instinct 5 cm 有限圆柱、100 点/脚、`sum(depth * (speed + 1e-6))` 动态穿入项，权重 −4。
- 保留脚尖接近立面/水平法向撞击项，权重 −2。
- 新增 `feet_loaded_overhang`，权重 −0.8。物理脚底采用当前 G1 的局部尺寸 x=[−5,12] cm、y=[−2.5,2.5] cm、z=−3.5 cm，50 点/脚。根据实际楼梯网格提取的同心方形踏面查询地面高度。
  - 脚底覆盖的踏面高差超过 5 cm，且低侧脚底离地超过 2.5 cm，才计入悬空支撑比例；额外 5 cm 间隙内线性渐增。
  - 竖直法向力 50–200 N 线性加载，低于 50 N 不计。静止承重也有代价；摆动、轻载卸力、单一平面上的脚尖滚动不触发。
  - 无效高度不被当作边缘。它是采样悬空比例，**不是接触压力或稳定裕度**；跨台阶的正常高负载蹬离仍可能有小代价，因此先用温和权重。
- 新增 `feet_swing_clearance`，权重 −1。上楼接近立面 12 cm 内，要求脚尖超过上沿 2.5 cm。离地时间 >20 ms、竖直力 <20 N，且水平目标方向指向高侧时启用。实际摆动速度变为零也不能消除这个信号；远处、支撑、下楼/后退和停止指令不受此项约束。
- AMP 风格系数 0.50 → 0.25；足滑权重 −0.10 → −0.20。
- 速度跟踪、巡航升档证据、下楼超速、长楼梯任务的 `dont_wait` 统一使用 root-link 的水平航向坐标速度，避免俯仰/竖直运动混入前向速度。
- 课程版本升为 9：续接策略、价值网络、AMP、优化器及地形/速度档位，清空旧版成功统计重新收集证据。
