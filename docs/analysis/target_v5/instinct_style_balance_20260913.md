# v5 蹲姿与 Instinct 风格平衡核对

2026-09-13。核对对象：当前 v5 49500 轮播放模型、截至 49584 轮的最近 500 轮统计，
本机 `/home/ljc/InstinctLab`、`/home/ljc/instinct_rl`，以及论文
[Hiking in the Wild, III-E](https://arxiv.org/html/2601.07718v1#S3.SS5)。
本轮仅研究与记录，没有改变训练、模型或播放参数。

## 结论和证据范围

任务执行有所改善，但风格奖励已十分微弱。持续蹲姿符合“任务允许低姿态移动，而风格信号
未有效约束关节姿态”的解释。奖励量纲和训练机制上的差异已由代码确认；各差异对蹲姿的
具体因果贡献，尚未通过独立训练对照确定。不能将蹲姿直接归因于相机遮挡，也不能保证
只增加风格权重就会恢复人类步态。

最近 500 轮记录：任务每步奖励 0.044749，风格每步奖励 0.000100991；等权混合后，
风格正奖励均值约为任务净奖励均值的 0.226%。这不是梯度贡献比例，也不衡量回报方差。
策略判别分 -0.999515、参考 +0.998323，风格零奖励比例 50.28%。
49500 checkpoint 的有效动作标准差均值 0.75432，29 个动作中 18 个达到上限 1.0。
可学习探索并没有自动变小；无采样噪声的 PLAY 仍显示低姿态，说明不能把问题仅归咎于
播放时的随机动作。

## 1. 奖励混合没有与 Instinct 对齐

令 `f(D)=max(0,1-(D-1)^2/4)`，`r_task=dt*sum(w_i*r_i)`，控制周期 `dt=.02 s`。

本机 Instinct parkour：

`r_total = r_task + 0.25*f(D)`

环境任务奖励乘 dt，算法生成的风格奖励没有再乘 dt。调用路径为：

- `InstinctLab/.../managers/reward_manager.py:141`：任务项乘 dt。
- `InstinctLab/.../parkour/config/g1/agents/instinct_rl_amp_cfg.py:50`：风格系数 .25。
- `instinct_rl/algorithms/wasabi.py:119`：生成未加权二次风格奖励。
- `instinct_rl/algorithms/ppo.py:151`：直接将辅助奖励乘系数后加到任务奖励。

本机 v5：

`r_total = 0.5*r_task + 0.5*(.02*2*f(D)) = 0.5*(r_task+.04*f(D))`

路径：`legged_lab/rsl_rl/amp/discriminator.py:162,171`、`ppo_amp.py:233`，并已核对训练保存
的 `params/agent.yaml`。在相同任务奖励、相同判别输出下，Instinct 风格相对任务的系数
是本任务的 `.25/.04=6.25` 倍。时间步缩放不是所有 AMP 都不能使用的错误，而是当前
“参考 Instinct”时没有对齐的约定。

若保留现有等权混合而把 style_reward_scale 从 2 改成 12.5，可对齐相对比例，
但总回报仍是 Instinct 的一半，价值损失/裁剪等训练动态不完全等价。
更清晰的适配是显式实现 `task + .25*f(D)`，分别记录原始 f、加权风格与任务奖励。
Instinct 日志中的 discriminator_reward 是未加权 f，我们的 style_reward_per_step 是
已乘 .04 的 f，原始曲线数字不能直接比较。

Instinct 的 parkour 配置只有一个 reward group、一个标量 critic。风格先加到任务中，
然后计算同一个 GAE 并归一化优势。它没有在这个任务上使用任务/风格独立 critic 或各自
归一化的优势；MoE 的 4 个专家也不是 4 个奖励通道。

## 2. 判别器稳定机制未成套适配

双方使用同样的二次风格公式和策略 -1/参考 +1 的 MSE 目标；公式本身不是缺失项。
论文强调梯度惩罚与权重衰减，不能据其“更平滑”描述推断实践中永不饱和。

本机 Instinct 具体做法：

- 对策略和参考拼接后的样本一起计算输入梯度惩罚，系数 5。
- 显式加入所有参数平方和惩罚 3e-4，以及最后一层权重平方和惩罚 .04。
- 判别器 AdamW，lr=1e-4，ReLU；当前配置无额外输入归一化器。
- 每轮当前 rollout 的 5 epochs × 4 minibatches = 20 次判别更新，然后清空 AMP storage。
- 判别器梯度目前没有单独 norm clip；AdamW 还使用其自身的默认 weight_decay。

当前 v5：

- 梯度惩罚只覆盖参考样本，系数 40；且输入已经过在线归一化。
- 使用 Adam 参数组 weight_decay，不是 Instinct 的显式正则损失组合。
- 判别器 lr=1e-5、ELU、每轮 2 次更新、10-rollout replay（新旧样本各半）。
- 归一化器只由策略样本更新，累计 1e8 帧后停止。此前检查未发现数值爆炸，不能单凭
  这项差异就认定它是故障根因。

依据：`instinct_rl/algorithms/wasabi.py:134,201,251,299`、
`instinct_rl/modules/discriminator.py:27`、本机 `ppo_amp.py:276` 与 `discriminator.py:179`。
因为输入尺度、正则形式和更新频率不同，不能把 40→5 或 lr×10 单独当成确定修复。
应在独立配置里成套实现对齐版本，并用受控对照检查风格奖励分布、关节运动和到达能力。

## 3. 当前奖励允许持续低姿态

- 当前根节点为 pelvis；base_height 门槛仅 0.2 m（通过高度扫描测地面相对高度），没有
  连续身高目标和正常行走时的膝关节姿态奖励。身体不倾斜并不等于膝盖伸展。
- 当前站立关节惩罚只覆盖髋 roll/yaw、手臂和腰，未覆盖膝盖；目标到达后的等待期间，
  也缺少与 Instinct 全关节站立项相同的约束。
- Instinct torso-root 的高度终止门槛是 .5，另有倾角终止和 torso/pelvis 姿态惩罚。
  两个工程的根节点和地面高度基准不同，不能直接将当前 .2 改成 .5。
- 两边 AMP 都包含 gravity/q/qdot/v/w 的 10 帧历史，没有直接的 root height 通道。
  所以“少了 AMP 身高观测”不是移植错误；关节姿态本来足以表达蹲姿，但判别奖励必须
  对策略学习仍有区分度。
- 当前 feet_air_time 只在平移指令非零时生效，Instinct 使用“平移或转向非零”条件，
  原地转向也获得单脚支撑/抬脚奖励。当前权重 .25、Instinct .5。这是另一处配套遗漏，
  可能促成搓脚式转向，尚未因果验证。
- 默认姿态并不能解释差异：本工程默认膝角 .3 rad，Instinct .669 rad，后者默认屈膝
  反而更大。持续蹲姿不能简单归因于默认膝角。
- 动作尺度/PD 也不同：当前统一 scale=.25，Instinct 按 `.25*effort_limit/kp` 逐关节
  设置；例如髋俯仰/膝/踝约 .5475/.3507/.4386。两边髋/膝/踝 kp 分别约
  100/150/40 与 40.18/99.10/28.50，后者还使用延迟执行器。因此原始动作 std 的数值
  不能脱离执行器参数直接比较。此项不是已证实的下蹲根因，不建议与 AMP 修复一起盲改。

## 下一版的修改与验收建议

1. 明确任务与风格奖励的单位，添加可选的 Instinct 加法混合方式与拆分日志。
2. 实现可选择的 Instinct 判别训练方式：双类样本梯度惩罚、显式正则、固定物理量尺度，
   不把多项不同语义的参数直接覆盖到旧模型训练配置。
3. 修复转向抬脚条件，并校准骨盆/躯干的高度与倾角终止。若再加低姿态辅助项，应保留
   台阶和落地时必要的屈膝余量，不强迫所有地形始终伸直膝盖。
4. 将探索作为单独对照；当前 .006 熵系数是照搬 Instinct，但未在本 PPOAMP 的奖励尺度
   下验证平衡，不应继续宣称它会自动降低噪声。观察有效动作 std 与各关节运动。
5. 固定模型、种子和地形，记录无噪声 PLAY 的膝屈曲分布、地面相对骨盆高度、步幅/
   单脚支撑、滑脚、有效到达和摔倒；同时对照参考动作分布。检查正常步态而非只看 D loss。

当前证据支持修正上述不一致，但不足以保证调整后直接续训旧蹲姿策略就能恢复参考风格。
