# 10000 与 57500 轮模型对照

2026-09-11，用户反映新版播放观感不如早期。确认当时播放为 model_57500.pt。
使用既有固定直行验收脚本，对 57500 轮模型复测，并对照昨日保存的 10000 轮记录。
相同任务、seed=42、32 个首回合、初始等级 0、0.5 m/s、零转向、确定性动作；
观测噪声和质量/摩擦随机化关闭，终点在自动重置前记录。

- 走满 20 秒：10000 轮 30/32；57500 轮 31/32。
- 净位移超过 4 米：两者均为 30/32。
- 全回合平均 XY 速度误差：0.305 → 0.235 m/s。
- 全回合平均转向误差：0.578 → 0.324 rad/s。
- 存活回合平均前向速度：0.714 → 0.684 m/s，仍高于 0.5 m/s 指令。

这个小样本测试未显示基本直行能力退化，但不足以判断高等级地形能力或动作自然程度。
两次结果不是同时运行，也不是多种子的统计显著性结论。
默认 Play 使用变化的速度/转向命令，而此验收固定直行，不能将两种场景直接等同。

训练最近窗口中风格奖励约 0.00061、任务奖励约 0.01587，两者混合权重均为 0.5，
因此风格项占平均混合奖励约 3.7%；10000 轮附近约为 43%。
判别器输出接近 -1，约 53% 的步风格奖励为零，提示风格信号弱、模仿目标需要排查。
这一平均标量占比不等于策略梯度占比。判别器本身也随训练改变，跨 checkpoint 的风格分数
下降不能单独证明实际步态变差，更不能单独确定因果原因。

建议用相同命令和地形比较视频/足部滑动、接触及姿态指标，再用固定判别器比较两个策略的动作分布。
不要仅按最新轮数或总奖励选择最佳模型；当前尚未改动训练，也未根据观感回滚模型。
