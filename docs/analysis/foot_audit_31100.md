## 检测定义与限制

仅统计有效行进帧（速度指令模长 >0.3 m/s）且该脚竖向接触力 >20 N 的脚采样时刻。
临边：沿脚底法线的 55 个射线样本中，相邻高度差 >5 cm 或有无命中。
支撑不足：脚底内部 27 个点中，距名义底面 ±2.5 cm 的比例 <90%。
外围约 2 cm 的安全圈也参与临边检测；完整支撑但靠近边缘与部分悬空分开统计。
所有有效帧均计入脚部统计，包括结束时未完成的回合；行为通过率只用结束回合。

这些是地形射线与合力代理，不是真实接触点、接触面积或压力分布。
正常蹬离、脚姿态变化、触碰立面可能触发。连续时间也不能单独证明危险。
方向统计覆盖整个行进阶段，并非仅楼梯踏面上的时刻。相邻帧高度相关，不是独立样本。

## 处理顺序

1. 回放显示左右脚“临边/临边且支撑不足/离地或轻触”，与实际动作对照。
2. 优先区分落地承重、中期支撑和正常蹬离；以支撑缺失程度、承重占比、持续时间形成分级代价，
   不建议仅继续提高当前二值临边项权重，更不建议所有临边立即终止。
3. 下楼先限制难度探索，处理持续超速与重心/落脚时序；保留前进要求，避免策略靠不走降低代价。
4. 使用同一组固定场景对照，要求支撑不足临边比例和失败率同时下降、速度误差改善，才接受奖励改动。

本次仅增加诊断与回放提示，没有进一步改变训练奖励或停止正式训练。
