支撑转换第二阶段：偏航与摆臂修正

2026-10-20 发布；实验完成于2026-10-16。原14700保留为主基线，16700为实验候选。

1000轮已完成，终点16700轮 · 4096环境，一半平地、一半桩路。

1000轮修正完成。192次过桩与停车全部通过，原模型和第一阶段也全部通过。相对14700平均偏航约2.17°降至1.70°，相对15700约2.60°降至1.69°；左侧臂腿协调从0.43恢复至0.63，右侧基本不变。步幅维持约49cm，步时稍慢，回放未见明显僵硬；身体晃动比14700约增加6%，仍需改进。保留14700为主基线，16700作偏航较好的实验候选，尚非全面胜出或论文方法的因果证明。

从15700继续：原策略动态控制全身，取消新增手臂修正，保留腰髋平衡能力；分开预测与控制梯度，轻度抑制持续修正偏置。运动与过桩奖励沿用原设置。

重复测量参考：同一14700的整段偏航均值为2.145° / 2.229°，单回合绝对差平均0.326°。仅一个重复对，用于了解复位/内部状态/数值波动，不是训练种子方差或置信区间。查看复测数据。
