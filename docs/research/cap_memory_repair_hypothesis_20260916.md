# CAP 同任务的替代机制：可修复的时序感知

日期：2026-09-16。状态：文献约束下的研究假设，未实现、未实验、未确认原创性。

## 研究目标

沿用 CAP 的目标：在深度噪声、部分遮挡、间歇故障下保持视觉运动能力。首轮使用静态地形和相同传感器，不引入移动平台、新传感器或新的导航任务。

当前优先验证的问题：短暂受损观测是否会污染时序表示，使图像恢复后仍持续输出错误动作？若成立，能否修复已传播的错误，同时保留仍然正确、目前处于盲区的地形记忆？

这不是已知的 CAP 实验失败结论。CAP 已讨论 WM overshoot，并用特征 dropout 缓解过度依赖；其附录 B.5 是全遮挡楼梯转平地案例。这里提出的“图像恢复后的污染残留”需要单独测量。

## 近邻工作与边界

- CAP (2026): 去噪 RSSM、本体 VAE、噪声课程和特征 dropout；已涉及错误记忆及恢复。不能声称首次处理错误视觉或记忆漂移。https://arxiv.org/html/2609.11553v1
- AME-2 (2026): 不确定性感知地形估计与时序融合；把未知区域保留为未知、加置信度地图均不足以构成新贡献。https://arxiv.org/html/2601.08485v1
- REAL (2026): FiLM-Mamba 时序视觉与物理引导状态估计；换时序骨干或融合本体感知不构成这里的贡献。https://arxiv.org/abs/2603.17653
- Distilling Realizable Students from Unrealizable Teachers (2025): 明确处理特权教师与学生的信息不对称。此前提出的“信息不足时不要强制模仿”已有近邻，不再作为优先方向。https://arxiv.org/abs/2505.09546
- Rethinking Robustness Assessment (2024，超出严格近两年窗口): 时序对抗扰动和策略增强；仅按时机攻击不够。https://arxiv.org/abs/2405.12424
- Neural Volumetric Memory (2023，基础工作): 视觉运动空间记忆。https://openaccess.thecvf.com/content/CVPR2023/papers/Yang_Neural_Volumetric_Memory_for_Visual_Locomotion_Control_CVPR_2023_paper.pdf
- From Faulty Memories to Corrected Actions (2026): 在语言模型智能体中使用依赖追踪和选择性回放修复记忆；所以“记忆回滚”概念也不能声称首次。任务、表示和实时约束与足式控制不同。https://arxiv.org/abs/2608.10502

有限检索尚未确认同一机制已在人形视觉运动上实现；这不等于证明没有相关工作。还需扩展鲁棒滤波、固定滞后平滑、异常观测撤销和递归网络状态修复文献。

## 待检验假设

H1：相同当前干净观测下，不同的短时污染历史造成持续的动作偏差。

H2：只降低当前视觉权重不能充分消除已写入时序状态的错误。

H3：选择性删除可疑观测并重算状态，比全重置更能保留盲区中的有用信息。

H4：上述收益在实际部署计算预算下仍成立，且正常视觉表现不明显退化。

任何一个假设都可能被实验否定。

## 最小机制设计

维护有限窗口 B_t={(视觉特征 e_i、本体观测 p_i、实际动作 a_i、时间戳)}，另存窗口起点的时序状态检查点。

当前时刻 t 的新深度可与历史点云在重叠区域做几何一致性检查；结合运动估计误差、观测年龄和有效像素信息，重新评估历史观测。必须允许误差来自位姿、真实环境变化和当前坏帧，不能把“不一致”直接等同于历史观测错误。

对高置信度判定为错误的观测，降低其权重或跳过该次视觉更新，然后从检查点重算至当前时刻：

    h_i* = F(h_(i-1)*, p_i, a_(i-1), e_i, w_(i|t))

其中 w_(i|t) 只依赖截至 t 已收到的信息。视觉缺失需要独立有效性标识，不能把零深度当成真实近距离物体。重算保留实际发生的本体状态与动作，只修复内部表示，不假设机器人身体能回到过去。

第一版使用整帧权重与短窗口，避免直接设计复杂依赖图。窗口长度由质量与计算开销实验决定。若污染早于检查点，则无法仅靠窗口内回放彻底修复；应报告这项限制。

在本体状态持续更新的控制回路旁运行修复过程；策略必须见过修复后的特征分布，避免直接替换隐藏状态产生新的动作突变。不能承诺满足 50 Hz，需实测总延迟及 p95/p99。

## 训练信号

仿真记录同一条实际轨迹的干净与受损观测。两条编码分支共享相同本体状态和实际动作历史，避免把不同运动轨迹造成的差异错误归因于记忆污染。

干净分支只作训练或诊断参照。部署端不得访问干净深度、真实损坏掩码、未来帧或仿真位姿。

可使用表示/动作一致性辅助损失，但只在已有观测支持恢复时施加；被完全遮挡且从未观察到的几何不能要求精确还原。最终仍通过闭环 PPO 检验落脚与稳定性。

## 先做诊断，再做算法

### A. 不运行新训练的离线诊断

在记录轨迹上，向历史深度注入有限时段的丢帧、边缘空洞、冻结旧帧与局部深度偏差；之后恢复真实观测。比较同一当前状态下，干净历史与受损历史产生的动作差异。

当前项目的深度历史是固定长度帧堆叠，不应称作 CAP 的递归隐藏状态。先测试坏帧离开窗口前后的影响；若增加递归基线，须分别报告。固定窗口自身的遗忘特性是重要基线。

离线差异不能等同于闭环失败率。

### B. 仿真中的诊断上限

在故障结束后的同一物理状态复制仿真分支，分别使用污染状态、清空状态、同一历史轨迹计算出的干净状态。状态替换仅用于判断修复潜在收益，不能当可部署方法。

### C. 部署可用机制

只使用在线一致性估计决定撤销，比较：原始策略、同训练课程的 CAP/可靠复现、当前观测门控、全重置、固定窗口遗忘、鲁棒滤波或短窗重估、选择性回放。

CAP 官方实现若尚未可用，明确标注复现版本、差异和复现成绩，不能称为官方结果。

匹配模型容量、训练预算、噪声数据，并另设相同额外计算预算的基线。

## 决定性实验

1. 干净→短时坏帧→干净：检查故障结束后的恢复时间。
2. 干净→坏帧→全遮挡：检查污染是否经记忆继续传播。
3. 先看见关键落脚区域，之后该区域离开视野：检查全重置是否丢掉必要信息，选择性修复是否保留。
4. 真实地形变化：新出现的台阶或视角揭示的边缘不应被当作坏帧删掉。
5. 位姿估计误差与轻微打滑：评估几何一致性模块的误判。
6. 独立噪声与持续遮挡：保留 CAP 原任务覆盖，不能只在定制故障上报告优势。

故障时长与强度是扫描参数，不是实验结果。实际物理相机遮挡/传感器异常与部署输入管线注入分开报告，不能将后者称为真实传感器故障。

## 指标与停止条件

指标：完整通行成功率、通行时间、恢复到稳定控制的时间、故障结束后若干步的落脚/姿态异常、错误删除正常观测的比例、盲区信息保留、推理延迟及最坏触发开销。恢复时间需预先固定误差阈值和持续满足时间；跌倒和超时单独计入，不能只统计成功恢复样本。

停止条件：

- 历史污染不产生明显持续影响，或 CAP 匹配训练后已充分抑制。
- 用干净历史状态替换也没有闭环收益，表明主要问题已转为身体状态失稳。
- 简单全重置、缩短窗口或鲁棒滤波达到相同效果。
- 收益仅来自更长历史、更大网络、更多训练或额外计算。
- 依赖无法在实机获得的故障标签/位姿真值。
- 正常地形突变被误删，或修复延迟抵消收益。

## 候选贡献表述

可争取验证：在间歇视觉退化下，通过当前证据重评历史观测并修复时序表示，在保留盲区有效信息的同时缩短感知恢复后的控制恢复时间。

不能声称：首次视觉盲走融合、首次发现记忆错误、首次在线记忆回滚、完整安全保证、已经超过 CAP、已确认可发表。
