## 修正

1. 平移指令存在时，按实际速度在指令方向的投影与指令速度之比计算 0~1 进展系数；反向移动为零，超速不额外加分。
2. 只有转向指令时，根据真实角速度同样计算进展，堵住目标在身后时原地站着获益的路径。
3. 速度跟踪任务奖励仍乘上述进展系数。令速度匹配项 T = `exp(-||v_xy-v_cmd||²/0.35² -(w_z-w_cmd)²/0.5²)`：有运动指令时，实际风格奖励为 `0.50 × 原始风格分 × 进展系数 × (0.5 + 0.5 × T)`。只给速度匹配部分加下限；有指令却静止、反向运动仍为零，低于目标速度仍按进展折减。进展达到 1 时，风格有效系数为 0.25~0.50，避免速度误差把风格信号几乎清零。停止指令保持原来的严格匹配 T，不给继续跑保底。超速仍折减但抑制比历史短训弱，是否重新超速需短训验证。
4. 终止帧使用重置前的进展系数，避免新回合零指令将失败帧风格奖励放大。
5. 用 v5 第 49500 轮初始化 actor 和观测归一化，保留已有移动能力。价值网络、判别器、优化器、学习轮数和动作噪声均重新初始化。初始动作标准差 0.25、范围 0.05~0.5，学习率固定 1e-4。
6. 首次迁移短训发现 v6 的 0.35 m 硬高度阈值会频繁终止旧 actor 的低姿态。v7 恢复来源 v5 的 0.20 m 跌倒高度下限，保留身体接触和过度倾斜终止，同时加入骨盆相对较低脚踝高度不足 0.55 m 的平方惩罚，权重 -6。低姿态仍是要改善的问题，不能因为不再触发高度终止就称为自然步态。

速度指令：上/下台阶、方块 0.45~0.8 m/s；上下坡 0.45~1.2 m/s；随机起伏地形 0.45~2.0 m/s。速度上限是训练目标，不代表模型已经掌握最高速度。

## 开始新实验

当前默认风格系数为 **0.50**，运动指令下速度匹配部分的下限为 **0.50**（此前两段短训为系数 0.25、无匹配下限）。任务奖励、参考数据及其权重不变。V6 和本地 InstinctLab 的基准系数仍为 0.25。本方案是本项目的折中实验，尚未经过新的策略训练验证，不能据此前短训结果声称已改善自然度。

新启动或恢复训练时生效；正在运行的训练和已有 checkpoint 的重放行为不会随配置编辑立即改变。默认实验后缀 `style05_floor05` 用于区分这次奖励调整。

```bash
cd /home/ljc/legged_lab_v3
ISAACLAB_PYTHON=/home/ljc/isaaclab/bin/python \
bash scripts/run_with_rsl5.sh scripts/rsl_rl/train.py \
  --task LeggedLab-Isaac-AMP-Depth-Target-G1-v3 \
  --viz none --device cuda:0 --num_envs 2048 \
  --max_iterations 30000 --seed 42 --run_name progress_walk_run_style05_floor05 \
  --init_actor /home/ljc/legged_lab_v3/logs/rsl_rl/g1_amp_depth_target_v5/2026-09-12_12-14-38_target_v5_scratch/model_49500.pt \
  agent.device=cuda:0 agent.resume=false
```

`--init_actor` 只用于初始化新实验，不能与 `--resume` 一起使用。继续已有 v7 训练时，使用 `--resume --load_run <v7目录名> --checkpoint <模型文件名>`，不传 `--init_actor`。RSL-RL 的 `--max_iterations` 表示本次额外训练轮数。
